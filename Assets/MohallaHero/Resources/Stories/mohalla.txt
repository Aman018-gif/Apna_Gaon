//  Conventions
//    Speaker: line             → who is talking ("You" is the player)
//    #civic:+5 #green:-3       → karma change when a choice is picked (civic, green, courage, honesty)
//    #trust:+15                → trust change for the person you are talking to
//    #why:...                  → the "Why it matters" card shown after the choice
//    #violence                 → an act of violence/vandalism (heavy rating penalty)
//
//  Talking to a character runs the knot  npc_<id>  below, which sends you to the right chapter.
//  Using a world object runs  obj_<kind>  (lights, taps, saplings, garbage, home) or the knot named by the object.
// ================================================================================================
